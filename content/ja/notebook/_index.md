# 備忘録

研究・実験・解析・日々の作業で得た知見を、短いメモとして残していくページです。

新しい記事から順に一覧表示されます。必要に応じて、後から追記・修正することがあります。

## このページの使い方

- 実験条件や手順の記録
- 解析コードや可視化の小さな工夫
- 論文・文献を読んだときの要点メモ
- トラブル対応ログ（再発防止用）

## タグの目安

`実験` / `解析` / `Hugo` / `論文メモ` など
